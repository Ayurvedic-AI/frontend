# _reference (not compiled)

Old svm-fe (manufacturing ERP) code kept only as a pattern reference: feature
folders, SDK-backed hooks, tables, drawers and the generated Orval SDK for the
old backend. It sits outside `src/`, so `tsc`, Vite, Vitest and ESLint ignore it.

Copy patterns from here when building School ERP screens; do not import from it.
Delete this folder once the School ERP has its own examples of every pattern.
